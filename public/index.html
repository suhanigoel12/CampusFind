API Endpoints Reference

Method Endpoint Access Description
GET /api/health Public Server uptime & MongoDB connection status
POST /api/auth/register Public Register student with bcrypt hashed password
POST /api/auth/login Public Login student & receive signed JWT
GET /api/items Public Browse all lost & found reports (supports search & filters)
POST /api/items Protected Create a new lost/found item report
PUT /api/items/:id Protected Update report details (title, location, desc)
PATCH /api/items/:id/resolve Protected Mark item as resolved when safely returned
DELETE /api/items/:id Protected Delete item report
